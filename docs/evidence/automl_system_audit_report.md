## 14. Recommended Upgrade Depth

### Classification: L2 - Engineering Upgrade Required

**Rationale:**

The system has genuine, substantial engineering: a working FastAPI backend with 8 agent modules, a real FAISS RAG pipeline, 8 pytest test files, a complete Next.js frontend with 10 pages covering the full ML pipeline, Prophet + ARIMA forecasting, SHAP explainability plots, and real model training reports. This is not a skeleton or prototype.

However, it cannot be classified as L1 (documentation polish only) because:

1. **CI/CD is missing in practice.** The `.github/workflows/` folder exists but contains no YAML files. CI/CD cannot be claimed until at least a test workflow is wired.
2. **docker-compose.yml is missing.** Backend and frontend cannot be run together via Docker, meaning the "deployment-ready" claim in the README badge cannot be fully supported.
3. **Benchmark evidence requires new scripts.** No API latency benchmarks exist. A `benchmark_api.py` script and results need to be created to support scalability claims.
4. **UI screenshots do not exist.** None can be extracted without running the app.
5. **Product naming is inconsistent** across 4+ locations and requires code-level changes (reports_routes.py, README, etc.).
6. **LangChain/ChromaDB overclaim** needs to be corrected in README to accurately describe the FAISS + SentenceTransformer + Ollama stack.

It is not L3 (full restructuring) because the core agent architecture, API design, and frontend structure are sound. No fundamental redesign is needed.
